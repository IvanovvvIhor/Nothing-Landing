# Nothing Landing Page

A responsive, minimalist single-page promotional website showcasing tech hardware, inspired by the Nothing brand.

## Project Description

The Nothing Landing Page is a modern website designed to provide visitors with a clean, visually striking overview of tech products. It includes sections for product highlights, categorized browsing, company background, and a responsive contact form. The page is built with a strong focus on clean architecture, maintainability, and user experience, making it easy for visitors to navigate and interact with the content.

## Technical Requirements

To run this project, you will need:

- **Node.js**: A JavaScript runtime built on Chrome's V8 JavaScript engine, used for local development tools.
- **NPM**: The Node.js package manager, used for managing project dependencies and running scripts.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. **Clone the repository:**

```bash
   git clone [https://github.com/IvanovvvIhor/layout_landing-page.git](https://github.com/IvanovvvIhor/layout_landing-page.git)


```

2. **Navigate to the project directory:**

```bash
   cd layout_landing-page


```

3. **Install dependencies:**

```bash
   npm install


```

4. **Start the local development server:**

```bash
   npm start


```

## Usage

After starting the project, it will be available on your local server. You can use the provided localhost URL in your terminal to preview the landing page and ensure it displays correctly across different screen sizes. You can also make changes to the project files and see updates according to your build tool's configuration.

## Features

* **Responsive Layout:** Adaptive design ensuring a seamless experience across desktop, tablet, and mobile devices.
* **Maintainable Codebase:** Strict adherence to BEM naming conventions and modular SCSS for scalable style management.
* **Interactive Navigation:** Functional mobile menu interface and structured anchor links for quick page navigation.
* **Form Handling:** Native form validation with an automatic input clearing mechanism upon successful submission.
* **Typography & UI:** Integration of custom Google Fonts (Space Grotesk, Space Mono) to match the strict, modern aesthetic of the original design.

## Technologies Used

This project was built using the following technologies:

* **HTML5:** For structuring the content on the web page, ensuring semantic and accessible markup.
* **SCSS:** A CSS preprocessor utilizing the BEM methodology to write cleaner, modular, and more maintainable stylesheets.
* **JavaScript:** Vanilla JS for adding interactivity and dynamic functionality, such as form handling and mobile menus.
* **NPM:** For managing project dependencies and task execution.
* **Git:** For version control, tracking changes to the codebase.
* **GitHub:** For hosting the repository and deployment via GitHub Pages.
